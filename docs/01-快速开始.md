# 01 · 快速开始

> 现在只有一条主路径：**把需求交给 AI，拿回一份文档。**
> 你想自己控每一步的话，看 [`12-prompts.md`](../skills/claude-anti-ban/references/12-prompts.md) 附录的「手动模式」。

## 30 秒版本

1. 复制下面这段，发给 Claude Code / Codex / Cursor（填上你的信息）
2. 回答它一次问完的 7 个选择题（不知道就选默认）
3. 等它跑完，拿到 `Claude-使用手册.docx`，照着做

```text
帮我把 Claude 的防封环境整套配好，全自动做完，中间只在必须我选的地方问我。

我的情况：
- 系统：【Windows 11 专业版 / macOS 14】
- 之前：【这个号被封过 / 没被封过】
- 这台电脑：【只登过这一个号 / 登过好几个号】
- 我有 VPS：【有，信息在下面 / 没有，帮我选一家】

如果我有 VPS：
  IP：【203.0.113.10】  端口：【22】  用户：【root】  密码：【粘贴】
  系统：【Ubuntu 22.04】  机房：【美国 纽约】

要求：
1. 先自己探测环境，别问我系统版本、时区、DNS 这些你能查到的
2. 需要我选的，一次问完，每个选项给我代价和推荐
3. 做完给我一份 Word 文档，教我每天怎么用、出问题怎么办
4. 其余中间文件你自己清掉，别留给我
```

---

## AI 会做什么（你不用管）

```
P0 探测 → P1 决策 → P2 清理 → P3 出口 → P4 一致性
        → P5 封堵 → P6 隔离 → P7 验收 → P8 出文档 → P9 清场
```

| 阶段 | 一句话 |
|---|---|
| P0 | 自己查系统、时区、语言、IPv6、DNS、代理、出口 IP |
| P1 | 按规则定方案（虚拟机 or 宿主机、时区、分流语义） |
| P2 | 需要时清旧痕迹：先备份，删除进废纸篓 |
| P3 | SSH 进 VPS，加固、装面板、建 VLESS-Reality、测速换 IP |
| P4 | 时区跟出口走、语言 en-US、关 IPv6、开 TUN、白名单式全代理 |
| P5 | DNS 三层封堵、WebRTC 策略关闭、NTP 走代理 |
| P6 | 需要就建 Hyper-V 干净虚拟机并打检查点 |
| P7 | 九项验收，每项要证据，不过就修 |
| P8 | 渲染唯一一份用户手册 |
| P9 | 删掉自己所有中间产物 |

## 你会被问到的 7 个问题

| # | 问题 | 默认 |
|---|---|---|
| ① | 出口放哪个国家 | 美国 |
| ② | VPS 怎么来 | 有就用有的 |
| ③ | 环境怎么隔离 | 被封过 → 虚拟机 |
| ④ | 旧痕迹清到什么程度 | 被封过 → 清到像新机器 |
| ⑤ | 怎么付款 | Google Play |
| ⑥ | 现有节点留不留 | 全部重建 |
| ⑦ | 文档格式 | Word |

除此之外它不该问你任何东西。如果它问了，回一句：

> 「这些你自己决定，按默认来，别再问我。」

## 你会拿到什么

**一份文档**：`Claude-使用手册.docx`（≤6 页，无术语）

```
① 每天开机 5 步
② 你现在用的是什么
③ 这 7 件事不要做
④ 出问题了，先看这张表
⑤ 万一被封了
⑥ 备份和恢复
⑦ 以后想改设置，把这句话发给 AI
附录 A 名词解释 / 附录 B 节点信息在哪看
```

其余全部由 AI 清理，包括：状态文件、临时脚本、日志、装完的系统镜像。

## 万一你已经被封过

在给 AI 的第一段话里明确写「这个号被封过」，它会自动：

1. 提高清理力度（清到像新机器）
2. 把方案定成虚拟机
3. 在文档里加上「申诉三步」

**顺序不能反**：先清 → 再换出口 → 再对齐 → 最后才登录。
