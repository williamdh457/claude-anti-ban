# 01 · 快速开始（30 分钟路径）

> 目标：从「什么都没有」到「检测页全绿，可以打开 Claude」。
> 前提：已有一台 VPS（没有的话先看 `skills/claude-anti-ban/references/01-vps.md` 第一节选商）。

---

## 时间分配

| 阶段 | 时间 | 做什么 |
|---|---|---|
| 0 | 5 min | 跑自检脚本，看现状 |
| 1 | 10 min | 把 VPS 信息交给 Agent，搭节点 |
| 2 | 5 min | 导入分流规则，开 TUN |
| 3 | 5 min | 时区 / 语言 / IPv6 / DNS / WebRTC |
| 4 | 5 min | 检测页验收 |

> 首次搭虚拟机另加 40–60 分钟（见 `07-hyperv.md`）。

---

## 阶段 0：看现状

```bash
bash skills/claude-anti-ban/scripts/check_env.sh
python3 skills/claude-anti-ban/scripts/ipcheck.py
```

```powershell
powershell -ExecutionPolicy Bypass -File skills\claude-anti-ban\scripts\check_env.ps1
```

记下这几项：

- 系统时区是不是 `Asia/Shanghai`
- 有没有 IPv6 出口
- DNS 是不是路由器地址
- 出口 IP 是哪国、什么 ASN

---

## 阶段 1：搭节点

把这条发给 Agent（填上你的 VPS 信息）：

```text
帮我在这台 VPS 上搭一个自用的 VLESS 节点：
IP【x.x.x.x】 端口【22】 用户【root】 密码【xxx】 系统【Ubuntu 22.04】 机房【美国纽约】
要求：
1) 先 SSH 上去确认系统和资源，基础加固（改 SSH 端口、ufw 只放 22/443）
2) VPS 时区设为机房所在地
3) 装 3x-ui，建 vless + reality 入站（端口 443，dest www.microsoft.com:443）
4) 导出 vless 链接和订阅地址给我
5) 每步给命令和输出，装完给我本地验证命令
不要装宝塔/Docker 面板/任何我没要求的服务。
```

详细版：`references/12-prompts.md` 第 2 节。

---

## 阶段 2：本地接上 + 分流

1. 装 **Clash Verge Rev**（[Releases](https://github.com/clash-verge-rev/clash-verge-rev/releases)）
2. 把 vless 链接转成订阅（sub.xeton.dev 或面板订阅地址）
3. 导入订阅 → 右键「使用」
4. **开启 TUN / 虚拟网卡模式**（关键：Claude 桌面端不认系统代理）
5. 用 `assets/routing/clash.yaml` 覆盖/追加 Claude 分流规则
6. 配置里加 `ipv6: false`，DNS 用 DoH 并走代理

```bash
curl -4 https://ipinfo.io/ip          # 应该是 VPS 的 IP
```

## 阶段 3：一致性

```bash
# 看出口在哪
curl -4 -s "http://ip-api.com/json/?fields=timezone,country,city"
```

```bash
# macOS
sudo systemsetup -settimezone America/New_York
sudo systemsetup -setusingnetworktime off
```

```powershell
# Windows（管理员）
tzutil /s "Eastern Standard Time"
Disable-NetAdapterBinding -Name "Wi-Fi" -ComponentID ms_tcpip6
```

- 语言：首选 `en-US`，浏览器语言列表**删掉** `zh-CN`
- 区域格式：`United States`
- DNS：代理端 DoH + fake-ip；浏览器安全 DNS 选 Cloudflare
- WebRTC：`chrome://flags/#webrtc-ip-handling-policy` → `disable_non_proxied_udp`

一键脚本：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\set_region.ps1 -DisableIPv6 -DisableAutoTime -Apply
```

```bash
bash scripts/set_region.sh --apply
```

---

## 阶段 4：验收

打开 <https://ip.net.coffee/claude/>，逐项对照：

| 项 | 通过 |
|---|---|
| 三个出口 IP | 完全一致 |
| IPv6 | 无 |
| Trust Score | ≥ 60，无 proxy/vpn 标记 |
| DNS 泄露 | 通过 |
| WebRTC UDP | 通过 |
| 时区 | 一致，无中国大陆时区黄标 |
| 语言 | 与 IP 地区匹配 |

**全绿之后，才打开 claude.ai。**
