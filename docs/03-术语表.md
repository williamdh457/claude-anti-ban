# 03 · 术语表

## 网络与代理

| 术语 | 含义 |
|---|---|
| **VPS** | Virtual Private Server，虚拟专用服务器。本手册指你在海外租的那台机器 |
| **出口 IP** | 你访问外部服务时对方看到的那个 IP。挂了代理后就是节点的 IP |
| **原生 IP** | 由当地运营商直接分配给该机房的 IP，地理位置判定准确 |
| **广播 IP** | 从别的地区「广播」过来的 IP 段，地理库常判错，风控容易标异常 |
| **住宅 IP / 家宽 IP** | 运营商分配给家庭宽带的 IP，风控眼里最像正常用户 |
| **机房 IP / IDC** | 数据中心段（AWS、Vultr、DO…），大量被代理和爬虫使用，信誉普遍偏低 |
| **ASN** | Autonomous System Number，自治系统号。IP 归属的运营商/机构编号，如 Anthropic 是 `AS399358` |
| **连坐** | 同一出口 IP 上有人违规被封，同 IP 的其他账号受牵连 |
| **分流** | 按域名/IP 决定哪些流量走代理、哪些直连 |
| **白名单模式** | 默认全部走代理，只把指定的国内服务放行直连（本手册推荐的语义） |
| **TUN / 虚拟网卡模式** | 代理客户端创建一块虚拟网卡接管全部流量，不认系统代理的程序（如 Claude 桌面端）也会被代理 |
| **系统代理** | 只影响遵守系统代理设置的程序（浏览器通常遵守，桌面端常常不遵守） |

## 协议与工具

| 术语 | 含义 |
|---|---|
| **VLESS** | 轻量代理协议，无内置加密，靠 TLS/Reality 保护 |
| **Reality** | Xray 的 TLS 伪装方案，借用真实网站证书握手，不需要自己买域名和证书 |
| **Trojan** | 伪装成 HTTPS 的代理协议，需要域名 + 证书 |
| **Hysteria2** | 基于 QUIC/UDP 的协议，速度快但对 UDP 环境敏感 |
| **3x-ui** | 带 Web 面板的 Xray 管理工具，一键脚本部署 |
| **Clash / Mihomo** | 主流代理客户端内核，支持规则分流 |
| **Clash Verge Rev** | Clash 的图形客户端，跨平台，支持 TUN |
| **subconverter** | 把 vless/ss 等链接转成 Clash/sing-box 订阅格式的工具 |
| **fake-ip** | 代理客户端的 DNS 模式：给域名分配假 IP，真正解析在代理端完成，从根上防 DNS 泄露 |

## 泄露与指纹

| 术语 | 含义 |
|---|---|
| **DNS 泄露** | 连接走了代理，但域名解析仍由本地运营商完成，暴露真实位置 |
| **DoH** | DNS over HTTPS，加密 DNS 查询 |
| **WebRTC** | 浏览器的实时通信能力，会通过 STUN 获取本机公网/内网 IP，绕过 HTTP 代理 |
| **STUN** | WebRTC 用来发现自身公网地址的协议（UDP） |
| **UDP 泄露** | UDP 流量没走代理，直接暴露真实 IP |
| **IPv6 偷跑** | 代理规则只匹配 IPv4，IPv6 请求走直连 |
| **指纹（fingerprint）** | 浏览器/设备的一组可识别特征：UA、Canvas、WebGL、字体、屏幕、时区、语言 |
| **Canvas / WebGL 指纹** | 通过绘图渲染结果的细微差异识别设备 |
| **JA3 / JA4** | TLS 握手指纹，能区分「真实浏览器」和「脚本/代理客户端」 |
| **Turnstile** | Cloudflare 的人机验证 |
| **NTP** | 网络时间协议（UDP），系统校时会暴露真实时区 |

## Claude 相关

| 术语 | 含义 |
|---|---|
| **Claude Code** | Anthropic 的命令行编程工具，有文件系统权限，会读系统环境 |
| **KYC** | Know Your Customer，身份核验。Claude 的证件核验由 Persona 承接 |
| **Persona** | 第三方身份验证服务商（`withpersona.com`） |
| **Trust Score** | 检测页给的 IP 信任评分，0–100 |
| **风控式验证** | Cloudflare 人机验证、邮箱/手机二次确认、临时禁用——由风控引擎实时决定 |
| **证件核验式验证** | Persona 上传政府证件 + 自拍，属合规流程，不是封号 |
| **养号** | 新号先低强度使用一段时间，建立正常使用画像，再逐步升级订阅 |
| **Pro / Max** | Claude 的订阅档位（$20 / $100 / $200 每月） |
| **连坐机制** | 见上，同 IP 违规会牵连其他账号 |

## 系统

| 术语 | 含义 |
|---|---|
| **Hyper-V** | Windows 内置的虚拟机平台，需专业版及以上 |
| **Gen 1 / Gen 2** | Hyper-V 虚拟机代数。Gen1 用 BIOS 引导（更稳），Gen2 用 UEFI + 安全启动 |
| **Default Switch** | Hyper-V 自带的 NAT 虚拟交换机，开箱能上网 |
| **检查点（Checkpoint）** | 虚拟机快照，可回滚到某个状态 |
| **增强会话模式** | Hyper-V 的高级连接模式，支持自适应分辨率、剪贴板、驱动器重定向 |
| **集成服务** | 虚拟机内的驱动与服务包，影响时间同步、网卡性能、WebGL |
| **差分磁盘** | 基于父盘增量写入的虚拟磁盘，节省空间但会膨胀 |
| **tzutil** | Windows 命令行时区工具 |
| **timedatectl** | Linux 的时区/时间管理命令 |
| **废纸篓 / 回收站** | 本手册所有清理动作的落点，不用 `rm -rf` |
