# 02 · 常见问题

## 一、IP 与出口

**Q：机房 IP 一定被封吗？**
不是。机房 IP 的风险在于「共享 + 被用烂 + 频繁跳变」。独享、原生段、长期固定，配齐其他项，实测能稳定用一年。真正该避免的是「共享机场出口」和「一天换三个国家」。

**Q：住宅 IP 是不是更好？**
是，但贵且不稳定。多数人用干净机房 IP 就够。判断标准看检测页：Trust Score、是否被标 proxy/vpn、滥用记录。

**Q：能不能用免费 VPN / 机场？**
不建议。共享出口 = 连坐；而且免费节点的 IP 段基本都在黑名单里。

**Q：IP 换太频繁会怎样？**
风控会认为「同一账号疑似被盗用」，直接弹二次验证甚至临时禁用。机房 IP 定下来就别动。

**Q：为什么检测页显示两个不同的出口 IP？**
分流失效（某类流量没走代理）或 IPv6 偷跑。开 TUN、关 IPv6、补全分流规则。

**Q：三个出口 IP 必须完全一致吗？**
是。中国出口 IPv4 / Cloudflare 出口 IP / Claude 出口 IP 不一致，说明有流量走了别的路径。

## 二、时区与语言

**Q：时区一定要改成美国吗？**
不一定。关键是「跟出口一致」。出口在美国就设美国时区；暂时不想换算，设 `Asia/Singapore` 或 `Asia/Taipei`（同为 UTC+8，钟表不变，但不是中国大陆时区）。

**Q：为什么改了时区检测页还是显示不一致？**
浏览器进程启动时才读时区，**必须重启浏览器**。另外确认改的是系统时区，不是浏览器插件。

**Q：界面语言能保留中文吗？**
可以。要改的是「首选语言顺序」和「区域格式」，以及浏览器语言列表里删掉 `zh-CN`。

**Q：装「时区伪装」插件行不行？**
不建议。插件只改 JS 层，NTP 和系统调用还是真时区，两套信号打架反而更异常。

**Q：NTP 也要管吗？**
要。系统校时会暴露真实时区。分流规则里加 `GEOSITE,category-ntp` 走代理，或关掉自动校时。

## 三、DNS 与 WebRTC

**Q：DNS 泄露很严重吗？**
很严重，而且最容易被忽略：连接 IP 在海外，DNS 查询从国内发出，地域直接矛盾。

**Q：浏览器开了安全 DNS 就够了吗？**
不够。如果代理没开 TUN，浏览器的 DoH 会直连 Cloudflare 本地节点，仍然暴露位置。**TUN 是前提。**

**Q：WebRTC 关了会影响用 Claude 吗？**
不会。Claude 网页版不用 WebRTC。放心关。

**Q：关了 WebRTC 检测页还是显示真实 IP？**
那大概率是 IPv6 泄露，不是 WebRTC。去关 IPv6。

**Q：公司网络下怎么配都不对？**
网关可能强制劫持 53 端口。用 DoH（443）绕过；或换网络。

## 四、痕迹清理

**Q：清理完就安全了吗？**
不是。清得掉的是本地痕迹；清不掉的是支付卡、手机号、邮箱、硬件指纹、服务端风控历史。换号要换**一整套身份要素**。

**Q：能不能直接删 `~/.claude`？**
不要。里面有 `projects`（项目会话）、`skills`、`hooks`、`CLAUDE.md`、`settings.json`。只清 `cache`、`logs`、`telemetry` 这些可再生的。

**Q：Claude 客户端打不开，要不要点「重置」？**
不要。点「终止 → 修复」，别点「重置」（会删掉登录态和全部数据）。

**Q：改 `userID` / `machineID` 有用吗？**
只是换本地标识，不代表平台侧的关联判断会变。别指望它解决封号。

**Q：Windows 改了 `MachineGuid` 是不是就换机器了？**
副作用大（影响激活和其他软件授权），收益不确定。换设备或换虚拟机更干净。

**Q：WSL 里也装过 Claude Code，要清吗？**
要。那是第二套 `~/.claude`，很容易漏。

## 五、虚拟机

**Q：一定要用虚拟机吗？**
不一定。但「被封过」「要长期跑 Claude Code」「这台机器登过多个号」这三种情况，强烈建议上。

**Q：虚拟机里 IP 会不一样吗？**
不会，走宿主机网络，出口 IP 相同。虚拟机的价值是**环境隔离**，不是 IP 隔离。

**Q：虚拟机性能够吗？**
4 vCPU + 6 GB 日常开发够用。大型编译会慢一些。别用动态内存，固定更稳。

**Q：家庭版 Windows 能用 Hyper-V 吗？**
官方不支持。升级专业版最省心；DISM 强开能用但更新后可能失效。

**Q：虚拟机里 WebGL 显示 `SwiftShader` 要紧吗？**
要紧，这是「非真实用户」特征。装集成服务、开增强会话能改善。

**Q：复制虚拟机能当新号用吗？**
硬件 ID 相同，必须 `-GenerateNewId` 并改主机名，且要换 IP 段、换账号。否则两台一样的机器同时在线反而是特征。

## 六、付款

**Q：没有外卡怎么办？**
国内发行的 Mastercard 双币/全币种卡通常可以，需先开通境外支付和无卡支付。或者走美国区 Google Play 礼品卡自己兑换。

**Q：Play 地区改错了怎么办？**
一年只能改一次。改之前想清楚。

**Q：代充安全吗？**
看卡源。盗刷卡会导致订阅回收 + 连坐封号。要求提供账号密码 + 验证码的一律别用。

**Q：一张卡能给两个账号付款吗？**
不建议。支付层关联比 IP 更硬。

**Q：订阅成功了但 Claude 还是 Free？**
确认 App 内登录的是同一个账号。

## 七、养号与使用

**Q：新号能马上开 Claude Code 吗？**
不建议。先免费养 1–3 个月，用网页版聊天，再升 Pro，再上 Code。

**Q：额度用满会怎样？**
「每月打满」本身就是异常使用特征。留 20–30% 余量。

**Q：只能美国白天用吗？**
没必要。中国作息 + 中文对话实测没问题。要控的是 IP 一致性、环境干净、额度强度。

**Q：要备小号吗？**
要。常备 2–3 个正在养的小号，大号出问题时能顶上。

**Q：Claude Code 接国产模型中转会怎样？**
`ANTHROPIC_BASE_URL` 指向中转站会被识别（社区披露的名单比对）。别在同一个环境里折腾。

## 八、被封之后

**Q：还能申诉吗？**
可以。`support.claude.com` → "My account has been disabled" / Appeal，或邮件 `support@anthropic.com`（主题 `account appeal`）。

**Q：申诉要注意什么？**
**先把 IP 修干净再申诉。** 用脏 IP 发申诉等于主动证明自己是异常用户。附上检测页全绿截图。

**Q：同一个号换个 IP 再登行不行？**
不行。服务端已经记录了之前的画像，换 IP 不改变历史。

**Q：多久能再注册？**
没有官方答案。实操上：清完痕迹、换整套身份要素、用干净环境注册，然后慢慢养。
