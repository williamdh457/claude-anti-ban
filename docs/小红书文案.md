## 三、正文（主推版 · 约 950 字，可直接复制）

```
做 Claude 这一年，被封过 3 次。
一开始以为是节点不行，换了一家又一家，还是封。

后来才想明白：不是 IP 脏，是「画像自相矛盾」。

🚩 三个最容易被忽略的信号

1️⃣ 系统时区
IP 在纽约，系统时区写着 Asia/Shanghai。
Claude Code 读的是系统时区，不是 IP。
代理骗得过服务器，骗不过自己的电脑。

2️⃣ 分流漏域名
它不只用 claude.ai，还会碰 CDN、登录认证、错误上报、时间同步。
漏一个，就有一半流量从本地直连出去。
一个账号两个出口，风控直接标红。

3️⃣ IPv6 偷跑
代理规则大多只管 IPv4。
IPv6 那条路绕过去，从你家宽带出去了，你还不知道。

🛡️ 几条基础习惯，比换节点有用

· 一号一机，别在同一台电脑登第二个号
· 节点定了别乱换，一天换三个国家最像被盗号
· 新号先免费养 1–3 个月，别注册当天就冲订阅
· 额度留两三成，每月打满本身就是异常特征
· 别用接码平台的号、临时邮箱、共享节点
· 一张卡只给一个号付款，支付层的关联比 IP 更硬
· 弹「验证」先别点，先看网络对不对
· 别把 Claude Code 接到国产模型中转上

💡 所以我做了什么

把「查环境 → 清旧号痕迹 → 搭节点 → 配分流（除白名单全走代理）
→ 时区语言按出口自动对齐 → 封掉 DNS 和 WebRTC 泄露
→ 需要就建一台干净虚拟机 → 九项验收 → 出一份 Word」
整套写成了一个 skill，丢给 AI 它自己跑完，中间只问我 7 个选择题。

📄 最后只拿到一份文档
不是配置报告，是「每天开机 5 步 + 出问题对照表」。

⚠️ 说实话
能降低「环境矛盾」的风险，但不保证不被封。
最终看平台规则，遇到问题走官方申诉，别反复试登录。

📦 这份流程我整理好了
私信我「1」，直接发你（不收费，也不卖号不代充）
```

### 6.4 私信话术（分场景）

| 对方说 | 你回 |

| 「1」 | 直接发上面的自动回复 |
| 「怎么用」 | 「把 README 里那段话复制给 Claude Code / Cursor，它自己跑完，最后给你一份 Word」 |

| 「能不能便宜点」 | 「代码本来就不要钱，你只需要自己有台服务器」 |

### 6.5 私信纪律

- **不在私信里发付款码、不发第三方链接**（容易被判营销/诈骗）
- 不发压缩包，只给仓库名，让对方自己去看
- 不承诺「保证不封」
- 一天私信别超过 50 条，超了容易被限制
- 对方没关注 → 先回一句「关注一下我才能发给你」，别硬发
