## 三、正文（主推版 · 约 420 字，可直接复制）

```
做 Claude 这一年，被限制过 3 次。
一开始以为是工具不行，换了一个又一个，还是不行。
后来才想明白：不是工具的问题，是「环境不一致」。

1️⃣ 时区、语言、区域格式，三个各说各话
系统时区是北京时间，界面语言是中文，区域格式又是另一个地方的。
在平台眼里，这台机器就不像一个正常用户在用自己的电脑。

2️⃣ 旧账号的痕迹没清干净
浏览器里的登录状态、客户端配置、缓存、历史。
换了号还留着，等于穿着旧衣服去换脸。

3️⃣ 一台电脑当好几个人用
同一台机器登两个号，装一堆来路不明的软件和插件。
环境越乱，越像「批量操作」。

几条基础习惯比换工具有用：
一号一机、别频繁换、新号先养 1–3 个月、
额度留两三成、别用临时号码、一张卡只付一个号。

我把「检查环境 → 清理 → 对齐 → 验收 → 出文档」
做成了一个自动化流程，交给 AI 跑完，中间只问我 7 个选择题。
最后只拿到一份文档：每天开机 5 步 + 出问题对照表。

个人经验，不构成使用建议，也不保证不被限制。
清单之后会放到主页合集，感兴趣的可以关注一下。
```

## 六、承接怎么做（合规版）

小红书对「导流到个人」是全网最严的一档，**「评论区扣1私发」「私信我1领取」属于典型踩线**，正文和评论都别写。合规的做法只有一条：**站内承接**。

### 6.1 正文/评论区允许出现什么

| 允许 | 不允许 |
|---|---|
| 「之后会放到主页合集里」 | 「私信我 1 发你」 |
| 「感兴趣的可以关注一下」 | 「扣 1」「评论区留 1」 |
| 「评论区聊聊你的情况」 | 「加我微信 / 发你邮箱」 |
| 「主页有整理好的清单」 | 「去某站搜 xxx」「站外链接」 |

### 6.2 私信只能被动响应

私信不是不能回，但**不能在公开内容里承诺「私发」**——一旦承诺，就是站外引流 + 诱导互动双命中。

对方主动来问时，正常聊、正常回答即可，别在私信里发付款码、二维码、压缩包。

### 6.3 对方问「在哪看」怎么回

| 对方问 | 回 |
|---|---|
| 「在哪看」 | 「我整理成清单了，这两天放到主页合集，关注一下就能看到」 |
| 「能不能发我」 | 「合集还没整理完，弄好会发出来，先关注吧」 |
| 「求链接」 | 「评论区聊就行，我看到了会回」 |
| 「加个微信」 | 不回，或「这里聊就好」 |

### 6.4 真正想长期承接，走这三条

1. **粉丝群**（1000 粉后开放）——站内，最稳
2. **专栏 / 合集**——站内，可沉淀
3. **小红书店铺**（如果要卖服务）——站内交易
