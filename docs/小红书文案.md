## 三、正文（主推版，可直接复制）

```
做 Claude 这一年，被封过 3 次。
一开始以为是节点不行，换了一家又一家，还是封。

后来才想明白：不是 IP 脏，是「画像自相矛盾」。

🚩 三个最容易被忽略的信号

1️⃣ 系统时区
你的 IP 在纽约，系统时区写着 Asia/Shanghai。
Claude Code 读的是系统时区，不是 IP。
代理骗得过服务器，骗不过自己的电脑。

2️⃣ 分流漏域名
它不只用 claude.ai，还会碰 CDN、登录认证、错误上报、时间同步。
漏一个，就有一半流量从本地直连出去。
同一个账号，两个出口，风控直接标红。

3️⃣ IPv6 偷跑
代理规则大多只管 IPv4。
IPv6 那条路绕过去，从你家宽带出去了，你还不知道。

💡 所以我做了什么

我把整套流程写成了一个 skill，丢给 AI，它自己跑完：

· 查环境（系统/时区/语言/IPv6/出口 IP）
· 清旧号痕迹（先备份，删除进废纸篓）
· 上服务器搭节点（VLESS + Reality）
· 配分流：除了白名单，全部走代理
· 时区语言按出口 IP 自动对齐
· 封掉 DNS 和 WebRTC 两个泄露口
· 需要的话建一台干净虚拟机，打完快照
· 九项验收，不过就修
· 最后给我一份 Word：每天怎么用、出问题怎么办
· 中间文件它自己删干净

全程只问我 7 个选择题，其余不用管。

📄 最后我只拿到一份文档
不是配置报告，是「每天开机 5 步 + 出问题对照表」。
我妈都能照着用。

⚠️ 说句实话
这套东西能降低「环境矛盾」带来的风险，但不能保证不被封。
账号状态最终还是看平台规则。
遇到问题走官方申诉，别反复试登录。

📦 代码开源了，搜 GitHub：claude-anti-ban
（或者评论区扣「1」，我发你）

有问题评论区问，尽量都回 🙌
```

## 七、发布注意

### 敏感词替换表（重要）

| 别写 | 改成 |
|---|---|
| 翻墙 / 科学上网 | 海外网络环境 / 出口 |
| 梯子 / 机场 | 节点 / 线路 |
| VPN | 网络工具 |
| 破解 / 白嫖 | 开源 / 免费方案 |
| 防封（标题里） | 稳定使用 / 少踩坑 |
| 绕过检测 | 环境对齐 |
| 代充 | 订阅方式 |

> 「防封」在正文里可以用，标题里建议换成「稳定使用」，通过率更高。

### 配图建议（6 张）

1. **封面**：上面三版选一版，大字 + 深色底
2. **痛点图**：三个信号做成三行对比（IP 纽约 / 时区上海 / 语言中文）
3. **检测页截图**：全绿那张（**把 IP 打码**）
4. **仓库目录截图**：一眼看出「有货」
5. **交付文档截图**：那份「每天开机 5 步」，最有说服力
6. **流程图**：P0→P9 一页看完

### 发布时间

- 工作日 **12:00–13:00** 或 **21:00–23:00**
- 避开周一周二上午（流量差）

### 不要做的

- 不要在正文里放 GitHub 链接（外链限流），放评论区或私信
- 不要一次发多篇同题材（会被判营销号）
- 不要在图片里出现服务器 IP、账号邮箱
