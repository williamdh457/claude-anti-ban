## [00:00] 开场：先看检测页

怎么长期稳定使用 Claude 订阅？本期视频带来一个实操加原理的完整教学。

我们先来看一个总则。先打开这个网页版的 Claude 检测器，我们要做的就是把这上面所有的东西都尽量弄成绿色。

其中最最重要的就是 IP 地址——应该确保 IP 地址是一个干净、纯粹、并且**独享**的 IP 地址。因为 Claude 是有**连坐机制**的：如果你同 IP 的人被封号，你很有可能会遭到连累。

〔注〕检测页：<https://ip.net.coffee/claude/>。判读标准见 `references/02-ip-check.md`。

---

## [00:31] 租海外服务器

所以我的做法是租用海外服务器：我电脑上的网络流量会先经过海外服务器，然后再到达 Claude。

这是一个海外服务器提供商的推荐列表，这里我以第 5 名的〔EOS〕为例——这里我只是举个例子，因为他家按月付费比较便宜，我做视频成本比较低，我并不是要推荐这一家。建议大家还是要多方对比，**网络速度**还有 **IP 的纯净度**是最关键的。

〔注〕选商维度见 `references/01-vps.md`。

## [01:02] 测 IP 质量

服务器准备好了以后点击进去，先点击**启动**按钮把它启动起来。

启动完成以后，我们测试一下这个 IP 质量怎么样：复制这个 IP 地址，然后来到测速网站，找到「在线 Ping」，把 IP 地址填上进行测速。

我们看到这个 IP 地址在中国大陆的大部分地区都可以直连的，不过这个速度有点慢。**如果不能直连，可以提交工单申请换一个 IP 地址。** 如果觉得速度慢，可以购买其他家云服务器厂商的服务器。

〔注〕ping.pe / itdog.cn 都可以。

## [01:36] SSH 登录

接下来我们把这个云服务器搭建成一个中转节点。

先打开终端，输入 `ssh`，接着输入用户名（就是这里的 root），然后 `@`，后面是服务器的 IP 地址，回车。接下来填写密码：我把这一串密码复制一下，然后 `Ctrl+V` 粘贴进服务器——**注意这里光标是不产生变化的，但它实际已经粘贴进来了**，接着回车。

这样我们就通过 SSH 的方式连接进了服务器。

## [01:52] 一键脚本 → 订阅链接

然后我们来到这个开源项目（一键部署脚本），往下找，这里有一个使用文档，找到这行安装命令，复制一下，粘贴进服务器回车执行。

我们看到这里生成了一个**红色的链接**，注意把它复制下来保存好。

〔注〕3x-ui / Xray / sing-box 的一键脚本与 Reality 配置见 `references/01-vps.md` 第五节。

## [02:07] 本地客户端：Clash Verge

有了这个订阅以后，接下来我们需要本地配置一个客户端。这里我使用的是 Clash Verge。

我们先来到它的 GitHub 主页，在 **Releases** 里面，根据你的操作系统下载对应的安装包。

---

## [02:22] vless 链接 → 订阅文件

打开软件以后，点击导入订阅，点击新建，这里选择**本地**，名字随便填一个。

然后我们来到这个地址——这个地址可以把一个 **vless** 类型的链接转换成一个订阅文件。我们把服务器里面的这一串 vless 链接粘贴过来，然后点击 Convert，这样会生成一个文件，我们点击 Download，把文件保存到桌面。

然后回到 Clash Verge，点击选择文件，选择我们刚才保存的文件，打开，然后点击保存按钮，右键点击「使用」。好，这样就配置完成了。

〔注〕在线转换：sub.xeton.dev；或用 3x-ui 面板自带的订阅地址。

---

## [02:53] 关键：虚拟网卡（TUN）模式

在网络设置这里，**一定要选择虚拟网卡模式**。使用虚拟网卡模式可以保证你这台电脑上面**所有的流量**都是走代理的，这样确保所有的网络流量不会有遗漏。为了稳定，我建议一定使用虚拟网卡模式。

这样配置完成以后，我们访问一下谷歌，能成功访问到谷歌，我们的节点代理就配置完成了。

---

## [03:08] 复检：两个 IPv4 变了，IPv6 没变

通过服务器把网络配置好以后，我们再来到 IP 检测看一下。

现在我们可以看到两个 IPv4 地址都已经是服务器的 IP 地址了，但是这里的 **IPv6 地址还是显示了我的地区**。

---

## [03:23] 关闭 IPv6

接下来我们把 IPv6 关闭掉，把这个问题解决。

在搜索栏搜索「网络」，点击「查看网络连接」，然后找到我的这个网卡（我现在使用的是无线网卡），找到它以后右键 → 属性，我们找到这里的 **IPv6 协议**，把它取消掉，然后点击确定。

再刷新一下，我们看到这三个 IP 地址都变成了我的服务器 IP 地址。

---

## [03:39] 时区：跟着服务器走

接下来还有一个问题。我们先看到这里的**时区**：我这台服务器显示是纽约的，所以应该把这里的时区设置成纽约时区。

我们在右下角点击「调整日期和时间」，把**自动时区设置关掉**，然后把时区调成这里的推荐时区 **UTC-4**，我选择大西洋时区，确保「自动调整为夏令时」这个开关开启。

再刷新一下，这里显示**时区一致**。

〔注〕更省事的做法是把系统时区设成 `Asia/Singapore`（同为 UTC+8，钟表不变），见 `references/04-timezone-locale.md`。

---

## [04:10] DNS：浏览器安全 DNS

接下来是这里的 DNS 问题。我们在浏览器里面找到设置，搜索 DNS，然后这里选择**使用安全的 DNS**，这里选一个服务商，一般选择 **Cloudflare**。

我们再刷新一下，看到 DNS 这里也没问题了。

---

## [04:27] 语言：只保留英语

最后一个就是语言。这里我们还是打开浏览器的设置，找到语言，把这个中文往下移、英文往上移，然后把两个中文给它**删除掉**——浏览器语言只保留英语。

然后我们再刷新一下，好，语言这里也没问题了。我们看到这里的色块**全部变绿了**。

唯一个小问题是这里是**机房 IP** 而不是家用宽带，不过我认为这个问题并不关键，因为我一年以来都是使用的服务器 IP，并不是家用宽带。

---

## [04:43] 顺序不能错：先全绿，再打开 Claude

这样我们网络准备好以后，我们就可以来到 Claude 的首页访问一下。

**注意这里的顺序不要搞错**：我们需要先在这个页面上确认所有的绿灯都亮起了，然后我们再去访问 Claude 的网站，这样才能确保万无一失。

**每次重启电脑**，也都先来检查一下这边的绿灯是不是都亮起了，然后再去登录 Claude 的网站，或者使用 Claude Code。

---

## [04:59] 登录：优先 Google 账户

接下来我们来登录 Claude。这里推荐使用**谷歌账户**登录。

这是我今天刚刚注册的一个谷歌账户。我们看到，如果你的 IP 足够干净纯粹的话，它是**不会弹 KYC 验证或者手机号验证**的，登录进来就可以直接使用 Claude。

除了使用谷歌账户，你也可以使用你自己的域名——比如我自己的这个 .com 结尾的域名，看起来就像一个公司的域名，很适合注册。

〔注〕自有域名 + 无限收件邮箱的做法，比临时邮箱稳得多。

---

## [05:20] 付费订阅：安卓 + Google Play

接着我们来看怎么获得一个 Claude 的付费订阅。这里我以**安卓手机**为例。

首先确保你的手机上有**美国的上网环境**，然后准备好这么两个软件：一个是 **Claude 的官方 App**，再有一个是 **Google Play**。

1. 我们先来到 Google Play 里面，点击右上角你的名字，然后在设置里面找到「常规」→「国家和地区设置」，这里把国家和地区**改成美国**。
2. 然后再回到你的名字，找到「订阅」这里，「付款方式」可以绑定一张**国内可以外币支付的 Master 信用卡**。
3. 下一步我们打开 Claude 的 App，然后登录一下你自己的账户。
4. 然后找到左上角的菜单，点击左下角的头像，点击**升级**。
5. 这里就可以使用 **Google Play 的付款渠道**订阅 Claude 的 Pro。

一开始的话，我建议先使用 **Pro 订阅**，先使用上几个月养养号。

〔注〕Play 地区一年只能改一次；账单地址建议填免税州。详见 `references/08-payment.md`。

## [06:10] Claude Code 放在 Hyper-V 虚拟机里

接下来我再分享一下怎么稳定使用 Claude Code。

这里我是单独在 Windows 的 **Hyper-V** 上面创建了一个虚拟机来使用 Claude Code（有关怎么使用 Hyper-V，在我的第一期视频里面就有过详细介绍）。

这里我们进入虚拟机看一眼：在这个虚拟机里面，我**只安装了一个浏览器、一个 VSCode，还有一个 Claude 的桌面端**，除此以外没有安装任何软件，尽量保持整个虚拟机的环境是干净纯粹的。

然后我已经把虚拟机的**时区改成了美国时间**，把虚拟机的**语言也改成了英语**，尽量保证**一机一号**登录上 Claude 账号，然后安安静静地使用。

**不要来回地切换账号**，也不要把 Claude Code 接入国产模型这么来回折腾。我们就一机一号、干净纯粹、安安静静使用就可以了。

如果想要折腾别的软件，或者使用国产模型，建议使用你的**宿主机**，或者你再新开一个虚拟机去折腾。Claude Code 的这个虚拟机，千万不要做任何的多余操作。

---

## [07:20] 养号节奏

最后再讲一个有用的点，那就是**养号**。

所谓养号就是：先注册一个免费账户，沟通沟通感情，等几个月以后再升级为 Pro 用户，然后开始使用 Claude Code。

注意：

- **不要把 Claude Code 的额度用得太满**，每个月留个 20% 到 30% 的余量；
- 也不要一直猛登 Claude Code；
- 同时要继续使用**网页聊天**，沟通感情；
- 再过几个月稳定以后，再升级成 **Max**。

最后一点是**未雨绸缪**：我们使用大号的时候，永远保持**两到三个小号**正在养着。
