## [00:00] 为什么要装虚拟机

如果你下载了一个神秘软件却不知道它的安全性；别人进你电脑的时候，担心被他发现一些藏得很深、或者藏得没那么深的小秘密——如果你也遇到以上尴尬的情况，这时候一个好的主意是给电脑**安装虚拟机**。

虚拟机：

- **独立于物理机**，可以运行不同的操作系统和应用程序；
- 即使有病毒攻击了虚拟机，**也不会危及到物理机的安全**；
- 如果给虚拟机设置好密码，其他人进你电脑也很难读取到其中的隐私信息；
- 可以很容易地**备份、复制和迁移**，可以根据需要从某个状态备份或者还原。

〔注〕本手册用虚拟机是为了「干净、可回滚、一号一机」，见 `references/13-vm-or-host.md`。

## [00:16] 三款虚拟机对比

| | VMware | VirtualBox | **Hyper-V** |
|---|---|---|---|
| 使用成本 | 高（官网售价 149 美元） | 免费（开源） | **低**（只需专业版 Windows） |
| 稳定性 | 中 | 低 | **最高**（内嵌在 Windows 中） |
| 性能 | 中 | 最低 | **最高**（启动最快、占用内存最小，支持 GPU 虚拟化） |

综上所述，我最推荐的虚拟机产品是 **Hyper-V**。

## [00:41] 第一步：获得纯净版 Windows 10 镜像

1. 打开浏览器，在 Bing 搜索「Windows 10」；
2. 找到「下载 Windows 10」，**注意看我们进入的是微软的官网**；
3. 找到「立即下载工具」；
4. 打开刚刚下好的工具，稍等片刻，点击「接受」；
5. **这一步是重点**：我们选择**「为另一台电脑创建安装介质」**；
6. 点击下一步，点击下一步；
7. 这里选择 **ISO 文件**，点击下一步；
8. 选择一个保存地址，点击保存；
9. 耐心等待进度条走完，我们就可以获得一个纯净版的 Windows 10 安装镜像。

〔注〕别用「系统之家」类修改版镜像。英文系统可在语言那步选 `English (United States)`。

---

## [01:03] 第二步：确认 Windows 版本

在搜索框搜索「设置」，选择左侧的「系统」，拉到最下面「系统信息」，我们可以看到 Windows 的版本。

- 如果此处显示是 **Windows 专业版或者旗舰版**，我们就可以使用 Hyper-V 了；
- 如果显示**家庭版或未激活**，我们需要对 Windows 进行升级：点击「产品密钥和激活」→「更改产品密钥」，输入一个专业版或旗舰版的产品密钥，对 Windows 进行升级或激活。产品密钥可以从某宝购买，只需要几块钱就可以了。填好产品密钥，点击下一页，系统会自动重启，然后我们的 Windows 就变成专业版或者旗舰版了。
- 如果不想升级 Windows 版本，这里可以在家庭版上执行一段脚本，强制开启 Hyper-V 功能（脚本可向博主索取）。

〔注〕强制开启属于不受官方支持的做法，更新后可能失效。本手册推荐直接升级专业版，见 `references/07-hyperv.md` 第二节。

---

## [01:33] 第三步：开启 Hyper-V 功能

1. 在搜索栏中输入「功能」，点击**「启用或关闭 Windows 功能」**；
2. 在这里选中 **Hyper-V**，点击确认；
3. 耐心等待进度条走完，点击**立即重新启动**；
4. 等待 Windows 启动后，我们电脑就拥有了 Hyper-V 的功能。

〔注〕命令行等价操作：`Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V-All -All`。

---

## [01:41] 第四步：创建虚拟机实例

1. 在搜索栏中搜索「Hyper-V」，点击进入 **Hyper-V 管理器**；
2. 在右上角「新建」→「虚拟机」，点击下一页；
3. 给虚拟机命个名，我们这里叫「Win10」。**如果 C 盘空间比较紧张，我们可以把虚拟机存放在其他位置**，点击下一页；
4. 指定代数：**保留第一代**——第一代的虚拟机比较稳定，点击下一页；
5. 分配内存：这里建议**至少分配 4 GB 以上**的内存，点击下一页；
6. 配置网络：这里选择 **Default Switch**，点击下一页；
7. 连接虚拟硬盘：大小随意分配，点击下一页；
8. 安装选项：这里选择**「从可启动的 CD/DVD 安装操作系统」**，点击「映像文件」，我们选择第一步里下载的映像文件，点击下一页，点击完成；
9. 耐心等待进度走完。

〔注〕本手册建议：内存固定 6 GB（不开动态内存）、磁盘 80 GB、关闭自动检查点。

---

## [02:37] 第五步：安装系统

1. 这里点击「连接」，点击「启动」；
2. 就像一台全新的电脑一样，它开始安装操作系统；
3. 点击下一步 → **现在安装**；
4. 点击**「我没有产品密钥」**；
5. 这里选 **Windows 10 专业版**；
6. 我接受 → 下一步；
7. 点击**自定义** → 点击下一步；
8. 耐心等待进度条走完；
9. 操作系统安装完毕后，虚拟机会进行重启；
10. 这里选择**「脱机账户」**即可（不登录微软账户）；
11. 点击**「有限的体验」**。

〔注〕区域设置那一步建议选 **United States**，键盘 `US`——这决定系统区域，后面不用再改。

## 本手册对视频的补充

视频只讲到「系统装完」。真正决定防封效果的是装完之后这几步（`references/07-hyperv.md` 第八节）：

1. **时区**：`tzutil /s "Eastern Standard Time"`，关掉自动时区；
2. **语言**：`Set-WinUserLanguageList en-US`，区域 `en-US`；
3. **关 IPv6**：`Disable-NetAdapterBinding -ComponentID ms_tcpip6`；
4. **装代理 + 开 TUN**（虚拟机内也要开，不能靠宿主机）；
5. **只装三个软件**：浏览器 / VSCode / Claude 桌面端；
6. **浏览器**：语言只留 en-US、安全 DNS、关 WebRTC；
7. **打检查点**，命名 `clean-baseline`。

之后每次环境出问题，直接回滚检查点，30 秒回到干净状态。
