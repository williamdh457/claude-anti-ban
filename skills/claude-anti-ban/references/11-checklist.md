# 11 · 三张清单（打印 / 贴桌面）

---

## 清单 A · 开机 60 秒自检

> 每次重启电脑、每次换网络、每次换节点，都跑一遍。**跑完才打开 Claude。**

```bash
bash scripts/check_env.sh          # macOS / Linux
powershell -ExecutionPolicy Bypass -File scripts\check_env.ps1   # Windows
```

| # | 检查项 | 通过标准 | ✅ |
|---|---|---|---|
| 1 | 代理客户端已启动 | 节点在线 | ☐ |
| 2 | TUN / 虚拟网卡模式 | 已开启 | ☐ |
| 3 | 出口 IP | = VPS IP（`curl -4 https://ipinfo.io/ip`） | ☐ |
| 4 | 三个出口 IP 一致 | 中国 / Cloudflare / Claude 同一个 | ☐ |
| 5 | IPv6 | 已禁用 / 无 IPv6 出口 | ☐ |
| 6 | DNS 泄露 | 通过，DNS 出口 = 代理出口 | ☐ |
| 7 | WebRTC / UDP | 通过，UDP 出口 = 代理出口 | ☐ |
| 8 | 系统时区 | 与出口地区一致，无「中国大陆时区」黄标 | ☐ |
| 9 | 浏览器语言 | `en-US`，无 `zh-CN` | ☐ |
| 10 | Trust Score | ≥ 60，无 VPN/Proxy/Tor/Crawler 标记 | ☐ |
| 11 | claude.ai 延迟 | < 400 ms | ☐ |

**11 项全过 → 打开 claude.ai。任何一项不过 → 先修。**

- [ ] 系统区域 = United States，首选语言 en-US
- [ ] 浏览器语言只留 en-US，地理位置拒绝
- [ ] 检测页全绿

### 注册后

## 清单 C · 换号（原号被封 / 要开小号）

> 顺序不能乱：**清 → 换 → 对齐 → 验 → 再登**。

### 1. 清（本地痕迹）

- [ ] 备份要留的数据（导出到与 Claude 无关的位置）
- [ ] 退出所有 Claude 客户端，结束残留进程
- [ ] 跑 `cleanup_traces.sh --dry-run` 看清单
- [ ] 跑 `cleanup_traces.sh --apply`
- [ ] 手动确认：浏览器 Profile、Claude 客户端目录、`~/.claude`、钥匙串条目
- [ ] 清 DNS 缓存、hosts、系统代理残留

### 2. 换（身份要素）

- [ ] 新出口 IP（新节点 / 新 VPS / 新机房）
- [ ] 新邮箱
- [ ] 新手机号（如需验证）
- [ ] 新支付卡（不给多号复用）
- [ ] 新虚拟机 / 新设备（最有效）

### 3. 对齐（环境一致性）

- [ ] 系统时区 = 新出口地区
- [ ] 语言 = en-US
- [ ] 区域 = United States
- [ ] IPv6 关闭
- [ ] DNS / WebRTC 通过
- [ ] 分流规则完整

### 4. 验

- [ ] 检测页 11 项全绿
- [ ] 三个出口 IP 一致
- [ ] 历史记录无异常跳变

### 5. 登

- [ ] 用新邮箱注册
- [ ] 不立刻付费
- [ ] 开始养号（1–3 个月）
- [ ] 把这次注册的 IP / 时间 / 邮箱记进自己的台账

## 附：日常纪律（贴在显示器上）

1. **一机一号**，不在同一环境登第二个号。
2. **不来回切号**，切号 = 关联。
3. **额度留 20–30% 余量**，别打满。
4. **网页聊天和 Claude Code 都用**，别只猛刷 API。
5. **IP 定了就别乱换**（机房 IP 尤其）。
6. **常备 2–3 个在养的小号**。
7. **出现验证弹窗先别点**，先查 IP。
8. **不接国产模型中转**，不把 Claude Code 指向第三方 `BASE_URL`。
9. **不在宿主机折腾**，折腾去另一台虚拟机。
10. **每周跑一次自检**，比出事再救便宜得多。
