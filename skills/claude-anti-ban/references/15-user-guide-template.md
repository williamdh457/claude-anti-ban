# 15 · 用户文档模板（唯一交付物）

> 这是 Agent 最后交给用户的那**一份**文档。它只有一个目的：**让不懂技术的人照着做就不会出错。**
> 不是配置报告，不是技术总结，不是「我做了什么」的流水账。

---

## 一、硬约束

| 约束 | 数值 |
|---|---|
| 篇幅 | ≤ 6 页（A4） |
| 术语 | 不出现 fake-ip / JA3 / ASN / Reality / TUN / DoH（要提就换成大白话） |
| 视角 | 第二人称「你」，不写「本 Agent 已为您配置」 |
| 每节 | 都是「你要做什么」，不是「配置了什么」 |
| 开头 | 一页内看完「每天怎么做」 |
| 结尾 | 一页「出问题怎么办」对照表 |

**语气**：像同事在教你，不像说明书。短句。能用「点这里」就不用「执行以下操作」。

---

## 二、结构（照抄这个骨架）

```
封面
  标题：你的 Claude 使用手册
  副标题：照着做就行，不用懂原理
  日期 / 版本

① 每天开机，就这 5 步
② 你现在用的是什么（一页纸看懂）
③ 这 7 件事不要做
④ 出问题了，先看这张表
⑤ 万一被封了
⑥ 备份和恢复
⑦ 以后想改设置，把这句话发给 AI

附录 A：这些名词是什么意思（可选，半页）
附录 B：你的节点信息在哪看（不写明文凭据）
```

---

## 三、逐节写什么

### ① 每天开机，就这 5 步

必须是可以打勾的清单，5 条以内，每条一行：

```
□ 1. 打开电脑上的 [代理客户端名称]，确认左下角显示「已连接」
□ 2. 打开浏览器，进 ip.net.coffee/claude，看到 6 个绿勾
□ 3. 全绿了，再打开 claude.ai（顺序别反）
□ 4. 用就行，别切账号、别登第二个号
□ 5. 关机前不用做任何事
```

> 如果用户的方案是虚拟机：第 1 步改成「打开 Hyper-V 管理器 → 双击 ClaudeBox → 连接」。

### ② 你现在用的是什么（一页纸）

用一张表，三列：**项目 / 你的情况 / 意味着什么**

| 项目 | 你的情况 | 意味着什么 |
|---|---|---|
| 你的网络出口 | 美国 · 纽约（203.0.113.x） | Claude 认为你在美国 |
| 系统时间 | 纽约时间（和北京差 13 小时） | 时间显示会不一样，正常 |
| 系统语言 | 英文优先，界面可以是中文 | 不用改回来 |
| 使用环境 | 单独的虚拟机 ClaudeBox | 你在电脑上装别的软件不影响它 |
| 订阅 | Pro，每月 $20 | 额度别用满，留两三成 |

### ③ 这 7 件事不要做

用「不要…因为…」的句式，一条一行：

```
1. 不要在没开代理的时候打开 Claude —— 会暴露你的真实位置
2. 不要一天换好几个节点 —— 会被当成账号被盗
3. 不要在同一台电脑上登第二个 Claude 账号 —— 两个号会被关联
4. 不要把额度用满 —— 每月留 20–30%
5. 不要在 Claude 的环境里装国产软件 / 接国产模型 —— 环境会变脏
6. 不要装「改时区」「改指纹」的浏览器插件 —— 反而更容易被识别
7. 不要把账号密码给别人（包括代充）—— 密码一给，号就不是你的了
```

### ④ 出问题了，先看这张表

三列：**你看到的 / 大概是什么原因 / 你该做什么**

| 你看到的 | 大概原因 | 你该做什么 |
|---|---|---|
| 登录一直转圈 | 网络没连上或节点挂了 | 检查代理是否连上；换个节点 |
| 让你验证「你是不是人」 | 出口 IP 被标记了 | 先别点，换节点后再试 |
| 突然要邮箱/手机验证 | 出口跳变了 | 换回原来的节点，再验证 |
| 桌面端点了没反应 | 客户端进程卡住 | 设置→应用→Claude→终止→修复（别点重置） |
| Claude Code 老断 | 网络抖动 / 并发太高 | 少开几个任务，换节点 |
| 付款被拒 | 卡或地区不对 | 换一张卡，或按第 ⑦ 节问 AI |

> 这一节的价值在于：**让用户在慌乱时不去点那个「验证」按钮。**

### ⑤ 万一被封了

三步，明确「先做什么、再做什么」：

```
1. 别急着注册新号。先把当前网络修好（打开检测页看有没有红/黄）
2. 到 support.claude.com 提交申诉，写清：账号邮箱、平时怎么用、没有共享账号
3. 等回复。这期间不要用同一个环境反复试登录
```

再加一句：「如果你要开新号，把这句话发给 AI：『帮我按换号流程重做一遍』」

### ⑥ 备份和恢复

| 你的东西 | 在哪 | 怎么恢复 |
|---|---|---|
| 系统备份（清理前） | `~/ClaudeBackups/20261117-0045/` | 告诉 AI「从备份恢复」 |
| 虚拟机快照 | Hyper-V → ClaudeBox → 检查点 `clean-baseline` | 右键 → 还原 |
| 节点配置 | 代理客户端的「订阅」里 | 重新导入订阅地址 |

### ⑦ 以后想改设置，把这句话发给 AI

给 5–6 句「可直接复制」的话，覆盖最常见的变更：

```
· 我想把出口换到日本：「帮我把节点换到日本，时区语言一起改，改完验证」
· 我想加一个小号：「帮我按换号流程开一个干净环境养小号」
· 检测页有黄的了：「帮我跑一遍自检，把不通过的项修掉」
· 我想换回宿主机用：「帮我把 Claude 环境从虚拟机迁回宿主机」
· 我想确认现在安不安全：「帮我做一次全面体检，给我结论」
```

### 附录 A：这些名词是什么意思

只翻 5–8 个最常出现的，一句话一个：

| 名词 | 大白话 |
|---|---|
| 出口 IP | 别人眼里你从哪来 |
| 节点 | 你借道的那台海外服务器 |
| 分流 | 哪些流量走海外、哪些走本地 |
| 虚拟机 | 电脑里的一台「电脑里的电脑」 |
| 检查点 | 给虚拟机拍的照片，出事能退回去 |
| 时区一致 | 你的钟表和你的网络出口在同一个地方 |

### 附录 B：你的节点信息在哪看

**不写明文凭据**，只写位置：

```
· 代理客户端：Clash Verge Rev → 订阅 → 名字叫 us-node
· 订阅地址：在客户端里，右键可以复制
· 服务器后台：3x-ui 面板 http://203.0.113.10:xxxxx（账号密码在你自己的密码管理器里）
```

## 四、反面例子（别这么写）

| ❌ 不要写 | ✅ 改成 |
|---|---|
| 「已配置 fake-ip 与 DoH，DNS 泄露已修复」 | 「你的网络查询不会再暴露你在国内」 |
| 「启用 TUN 模式接管全局流量」 | 「打开那个开关，所有软件都会走海外」 |
| 「ASN 为 AS7488，判定为 IDC」 | 「你的服务器是机房线路，够用，不用换」 |
| 「执行 `tzutil /s "Eastern Standard Time"`」 | 「时区已经改成纽约时间，你不用管」 |
| 「本 Agent 已完成 9 项配置」 | 「你现在可以正常用了，下面是每天要做的」 |

## 五、生成方式

```bash
python3 scripts/render_user_guide.py \
  --state .cab-state/state.json \
  --out ./Claude-使用手册 \
  --format both
```

脚本会按本模板渲染 Markdown 与 Word 两份，内容一致。
生成后 Agent 要自己读一遍，检查：

- [ ] 有没有漏填的占位符（`{{...}}`）
- [ ] 有没有出现术语
- [ ] 页数是否 ≤ 6
- [ ] 每天 5 步是否和用户的实际方案一致（虚拟机 vs 宿主机）
