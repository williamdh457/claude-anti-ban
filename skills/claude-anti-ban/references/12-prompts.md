# 12 · 怎么把这件事交给 AI（用户版）

> 你不需要懂任何技术。**发一段话，回答几个选择题，等一份文档。**
> 其余全是 AI 的活：探测、清理、搭节点、配规则、对齐时区、封泄露、建虚拟机、验收、清场。

---

## 一、一句话交付（复制这段就行）

```text
帮我把 Claude 的防封环境整套配好，全自动做完，中间只在必须我选的地方问我。

我的情况：
- 系统：【Windows 11 专业版 / macOS 14】
- 之前：【这个号被封过 / 没被封过】
- 这台电脑：【只登过这一个号 / 登过好几个号】
- 我有 VPS：【有，信息在下面 / 没有，帮我选一家】

如果我有 VPS：
  IP：【203.0.113.10】  端口：【22】  用户：【root】  密码：【粘贴】
  系统：【Ubuntu 22.04】  机房：【美国 纽约】

要求：
1. 先自己探测环境，别问我系统版本、时区、DNS 这些你能查到的
2. 需要我选的，一次问完，每个选项给我代价和推荐
3. 做完给我一份 Word 文档，教我每天怎么用、出问题怎么办
4. 其余中间文件你自己清掉，别留给我
```

发完就可以去干别的了。

---

## 二、AI 会问你什么（最多 7 个，一次问完）

| # | 问题 | 选项 | 不知道就选 |
|---|---|---|---|
| ① | 出口放哪个国家 | 美国 / 日本 / 新加坡 | **美国** |
| ② | VPS 怎么来 | 我有 / 帮我选一家买 / 先用现成机场 | 有就选有 |
| ③ | 环境怎么隔离 | A 单独虚拟机 / B 直接这台电脑 / C 混合 | **被封过选 A，没封过选 B** |
| ④ | 旧痕迹清到什么程度 | 只清缓存 / 连登录状态一起清 / 清到像新机器 | **被封过选第三档** |
| ⑤ | 怎么付款 | 自己绑卡走 Google Play / 礼品卡 / 代充 | **Google Play** |
| ⑥ | 现有节点留不留 | 留 / 全部重建 | **全部重建** |
| ⑦ | 文档要什么格式 | Word / Markdown | **Word** |

**你只在这 7 个地方会被打断。** 其他任何问题（「要不要备份」「能不能改时区」「要不要开代理模式」）都不该出现——那是它自己的活。

如果它问了这 7 个以外的问题，回一句：

> 「这些你自己决定，按默认来，别再问我。」

---

## 三、AI 会自动做完的 10 件事（你不用管）

1. 查你的系统版本、内存、磁盘、CPU 能不能跑虚拟机
2. 查你现在时区、语言、IPv6、DNS、出口 IP 是什么状态
3. 清掉旧账号留下的本地痕迹（先备份，删的进废纸篓）
4. SSH 进你的 VPS，做基础加固，把服务器时区调对
5. 装面板、建 VLESS + Reality 节点、导出订阅
6. 测 IP 纯净度和中国大陆连通性，不合格自动换 IP
7. 配「除白名单外全部走代理」的分流规则，Claude 域名最高优先级
8. 按出口 IP 改时区、语言、区域，关 IPv6，封 DNS 和 WebRTC 泄露
9. 需要的话建一台 Hyper-V 干净虚拟机，装好系统、配好环境、打快照
10. 逐项验收（九项），不过就修；修不掉的写进文档告诉你

---

## 四、你最后会拿到什么

**只有一份文档**：`Claude-使用手册.docx`

里面有：

| 章节 | 内容 |
|---|---|
| ① 每天开机 5 步 | 照着做就不会错，5 条 |
| ② 你现在用的是什么 | 一页纸看懂：出口在哪、时区、语言、隔离方式、订阅 |
| ③ 这 7 件事不要做 | 每一条都写了「为什么」 |
| ④ 出问题了先看这张表 | 症状 → 原因 → 你该做什么 |
| ⑤ 万一被封了 | 三步申诉 |
| ⑥ 备份和恢复 | 备份在哪、怎么退回去 |
| ⑦ 以后想改设置 | 5 句可以直接复制给 AI 的话 |

不超过 6 页，不出现任何技术术语。

**其他所有东西**（临时脚本、状态文件、日志、装完的系统镜像）AI 会自己删掉。

## 五、中途你可以说的话

| 你想 | 就说 |
|---|---|
| 别问了，你决定 | 「剩下的你自己定，按默认来」 |
| 我想看着你改 | 「每一步先告诉我要改什么，再动手」 |
| 先别动我的文件 | 「清理阶段只清缓存，别碰桌面端数据」 |
| 我改主意了，换地区 | 「出口改成日本，其他按原计划」 |
| 停下来 | 「先停，把已经做完的和没做的列给我」 |

## 六、做完之后，你只需要记住三句话

1. **先看检测页，全绿再打开 Claude。**
2. **不要一天换好几个节点，不要在这台机器上登第二个号。**
3. **任何弹窗让你「验证」的时候，先别点，先看网络。**

## 附录：手动模式（想自己控每一步的人用）

如果你不想全自动，想一步一步来，就按下面五段分别发指令。每段都写清了「动作」和「验收」。

<details>
<summary><b>① 体检 + 清理</b></summary>

```text
先只读审计，不要删任何东西。列出：系统版本/时区/语言/IPv6/DNS/系统代理/出口 IP，
以及 Claude 相关目录（~/.claude、Application Support/Claude、%APPDATA%\Claude 等）的位置和体积。
然后给我清理计划：要删什么、备份到哪、哪些绝对不动（projects/sessions/history/skills/hooks/CLAUDE.md/settings.json）。
我确认后你才执行，删除一律进废纸篓，不用 rm -rf。
```

</details>

<details>
<summary><b>② 搭节点</b></summary>

```text
VPS：IP【x.x.x.x】 端口【22】 用户【root】 密码【xxx】 系统【Ubuntu 22.04】 机房【美国纽约】
按顺序做：SSH 登录确认资源 → 基础加固（改 SSH 端口、ufw 只放 SSH+443）→ 时区设为机房所在地
→ 装 3x-ui → 建 vless+reality 入站（443/tcp/xtls-rprx-vision/dest www.microsoft.com:443）
→ 导出 vless 链接和订阅地址 → 给我本地验证命令。不要装宝塔/Docker 面板/任何额外服务。
```

</details>

<details>
<summary><b>③ 分流规则</b></summary>

```text
规则语义：除白名单外全部走代理。final 指向 PROXY，Claude 规则放最前面，白名单（局域网+geosite:cn+geoip:cn）放后面。
Claude 规则必须含：核心 7 个域名 + CDN + 认证 + KYC + 监控（sentry/statsig/datadog/sift）+ 客服 + NTP
+ IP 兜底 160.79.104.0/21、2607:6bc0::/32、IP-ASN 399358（都带 no-resolve）。
改完给我 diff，并告诉我怎么验证三个出口 IP 一致。
```

</details>

<details>
<summary><b>④ 时区 / 语言 / 泄露</b></summary>

```text
先查出口 IP 归属地，然后：系统时区=出口时区、关自动校时、区域 en-US、首选语言 en-US、
浏览器语言删掉 zh-CN、关 IPv6、DNS 用 DoH 且走代理、WebRTC 关 non-proxied UDP。
不要装时区伪装/指纹伪装插件。做完给我 5 条验证命令和预期输出。
```

</details>

<details>
<summary><b>⑤ 虚拟机（可选）</b></summary>

```text
在 Hyper-V 里建一台只给 Claude 用的虚拟机：Gen1、内存 6GB 固定、磁盘 80GB、Default Switch、挂 ISO。
装完做干净基线：时区美国、语言英语、关 IPv6、装代理开 TUN、只装浏览器/VSCode/Claude 桌面端、打检查点 clean-baseline。
给我一份开机自检清单。
```

</details>

<details>
<summary><b>⑥ 验收</b></summary>

```text
逐项检查并给 ✅/⚠️/❌：三个出口 IP 是否一致、IPv6 是否有出口、Trust Score、DNS、WebRTC、
时区、语言、claude.ai 延迟、分流是否命中。每项要有实际命令输出，不要只说「已配置」。
最后给一句话结论：现在能不能打开 claude.ai。
```

</details>
